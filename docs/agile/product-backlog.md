## Definition of Ready
- Story has a clear user, goal, benefit and acceptance criteria.
- Dependencies identified; estimate agreed by the team.

## Definition of Done
- Acceptance criteria met and demoed.
- Automated tests written and passing in CI.
- Code reviewed via pull request and merged to `develop`.
- No secrets committed; docs updated where relevant.
