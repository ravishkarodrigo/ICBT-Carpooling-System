## A note on AI use (per the assessment brief)

This assessment is marked as **AI Acknowledged**. If you use AI tools while
developing, keep a short statement (see [`ai-acknowledgement.md`](ai-acknowledgement.md))
describing what support you used and how you developed it into your own work,
and reference sources appropriately. Make sure every team member can explain any
part of the submission if asked.
